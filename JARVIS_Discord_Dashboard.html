Deployment checklist

  1. Deploy the backend
    Run the JARVIS FastAPI service on a host with a public HTTPS address.
  2. Configure secrets on the host
    Set the Discord public key, application ID, bot token, and AI provider credentials as environment variables. Never put tokens in this HTML page.
  3. Register the slash command
    Run the backend project's register_command.py with its configured environment.
  4. Set Discord's endpoint
    In Developer Portal, use the exact interactions URL shown on the left.
  5. Validate
    Discord sends a signed PING request. The backend must verify the signature and return the PONG response.
